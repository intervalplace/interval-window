# poly.pizza -- the two static creatures, by Quaternius

`raven.glb` and `mermaid.glb` were fetched one at a time from poly.pizza with
`Tools/polypizza.py`, which reads the licence off each model's OWN page and
refuses anything that is not CC0. Both answer:

Licence: **CC0 1.0 Universal**, public domain dedication, by Quaternius.
https://creativecommons.org/publicdomain/zero/1.0/

    raven.glb    poly.pizza/m/gYYC0gYMnw   sha256 d0d08da2e47307301cfc...
    mermaid.glb  poly.pizza/m/wSlNdvboIS   sha256 72522fc4496f81f3d4e1...

The slugs are recorded because the file names are OURS and not theirs, and
without the slug nobody can check this claim. Both were re-fetched on
2026-10-14 and are byte-identical to the copies in this folder, which is how
the pairing was proved rather than remembered.

AND NEITHER IS THE CREATURE ITS NAME SAYS. `raven.glb` holds one mesh called
"Ernest", a blue and green bird with an orange beak; `mermaid.glb` holds one
called "Sea monster Scene", which is a tentacle, a rock and a ship. They were
taken as the first CC0 hit for a search word without anyone looking at the
model. The crow is forged now (see `crow` in Tools/make_art.py) and the siren
is still waiting on art.

`goblin_d.glb` in this folder has NO licence record and is not covered by
either heading above. The same is true of the goblins, the ogre, the orc, the
monsters and the mermaid in `Art/Wild`, whose README names only Quaternius's
Ultimate Animated Animals pack, and a goblin is not an animal. poly.pizza
hosts CC-BY work by Quaternius alongside the CC0, so the author's name is not
the licence: `KaVJET0WHx` is an ogre by Quaternius under CC-BY. Those files
want the same treatment this entry had before anybody relies on them.
