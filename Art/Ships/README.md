# Quaternius — Ships Pack

Author: Quaternius (https://quaternius.com)
Pack page: https://quaternius.com/packs/ships.html
Licence: **CC0 1.0 Universal**, declared in this folder's own `License.txt`.

Fetched from the author's own Google Drive mirror, which the pack page links.

Six models: Boat, Lifeboat, BoatWSail, `Viking boat`, `Sail ship`, CruiseShip.
Fetched for the three words no kit here could answer -- `ferry`,
`landmark.upturned-boat` and `landmark.shipwreck` -- which were the last of the
prop backlog that a box could not honestly stand in for. A boat is not a shape
that can be faked.

CruiseShip is modern and has no use in this world; it is kept because deleting
one file out of a CC0 pack makes the folder no longer the pack.
