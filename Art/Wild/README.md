# AND THE NINE IN HERE THAT ARE NOT ANIMALS

The heading above names Quaternius's **Ultimate Animated Animals**, and its
licence was read from that pack's own file in this folder. That covers the
animals: `crab`, `deer`, `goat`, `snake`, `wolf_a`, `wolf_b`.

It does not cover a goblin. Nine files in here are monsters and people, they
came one at a time from poly.pizza rather than from that pack, and until now
they sat under a heading that did not describe them.

Each was re-fetched on 2026-10-15 with `Tools/polypizza.py`, which reads the
licence off the model's OWN page and refuses anything that is not CC0, and
each came back **byte-identical** to the copy here. The pairing is proved
rather than remembered, and the slug is recorded because the file names are
ours and not theirs: without it nobody can check this.
