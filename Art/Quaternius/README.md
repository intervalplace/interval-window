# Quaternius -- Ultimate Modular Characters (Men & Women)

Source: https://quaternius.com/packs/ultimatemodularcharacters.html
        https://quaternius.com/packs/ultimatemodularwomen.html
Author: Quaternius (https://quaternius.com, https://www.patreon.com/quaternius)
Licence: **CC0 1.0 Universal** (see `Men/License.txt`, `Women/License.txt`)

Downloaded from the author's own Google Drive mirrors, from the folder the pack's
"How To Use.txt" names as the Unreal-facing one: *Separate Skeletal Meshes and
Animations*. Each outfit is four skeletal meshes -- Body, Head, Legs, Feet -- sharing
one skeleton, which is exactly the leader/follower arrangement `AIntervalCitizens`
already uses. `Animations.fbx` carries the shared animation set.

Only the outfits that suit a medieval world were taken:
  Men:   Adventurer, Farmer, King, Worker (+ Weapons/Sword)
  Women: Adventurer, Medieval, Witch, Worker (+ Sword)

The `Women/License.txt` says "Ultimate Modular Males" in its header -- that is the
author's copy-paste slip in the original file. The CC0 dedication in it, and the
CC0 tag on the pack's own page, are what govern.

These replace the KayKit characters, whose chibi proportions did not sit well
against this world's buildings.
